# List Comprehenssion 100 Task

Using the file [London Stock Exchange data from 2018](Data/LSE.csv) write a Python script using **List Comprehension** to:

* List all companies who have not submitted their statement in 2018
* Obtain a list of companies grouped by their **Net Asset Value** using the following ranges:
    * Negative value
    * Value between 0 - 100 (not inclusive)
    * Value from 100 but less than 1000
    * Value above 1000
* Provide a list of companies who's **Net Asset Value** is positive, and have a **Dividend Yield (%)** above **10%**.
